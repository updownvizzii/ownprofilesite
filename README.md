# Vignesh Ganaraja Bhat - Portfolio Website

A cutting-edge, top-tier portfolio website showcasing the work of Vignesh Ganaraja Bhat, a Full-Stack AI/ML Engineer with 3+ years of experience building production systems.

## 🚀 Features

- **3D Animations**: Interactive Three.js scenes with typing animations
- **Modern Design**: Glassmorphism UI with gradient accents
- **Smooth Animations**: Framer Motion powered transitions
- **Responsive**: Fully responsive design for all devices
- **Performance Optimized**: Next.js 14 with App Router
- **SEO Ready**: Optimized metadata and structure

## 🛠️ Tech Stack

- **Framework**: Next.js 14
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **3D Graphics**: Three.js, React Three Fiber, Drei
- **Animations**: Framer Motion
- **Icons**: React Icons

## 📦 Installation

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🏗️ Build for Production

```bash
npm run build
npm start
```
